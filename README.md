# MATHESH K | Front-End Developer Portfolio

A modern, highly aesthetic front-end developer portfolio for Mathesh K, built with a refined brutalist design philosophy.

## Overview
This portfolio was meticulously crafted to highlight my skills as a Front-End Web Developer and BCA Student. It features a stunning Light/Dark mode implementation, glassmorphism UI elements, smooth scrolling animations, and a bold typographical layout.

## Features
- **Striking Aesthetics**: A brutalist-inspired design using `Bebas Neue` and `Outfit` typography.
- **Theme Support**: Seamless Light/Dark mode toggle with high-impact color palettes.
- **Micro-interactions**: Custom magnetic cursor, hover effects, and CSS-only marquee.
- **Responsive Design**: Flawless layout across all screen sizes.
- **No-Framework Speed**: Built purely with Vanilla HTML, CSS, and JS for maximum performance.

## Tech Stack
- HTML5
- CSS3 (Vanilla, CSS Variables, Glassmorphism, CSS Grid & Flexbox)
- JavaScript (DOM Manipulation, Intersection Observer API for scroll animations)

## Running Locally
Since this project uses pure HTML/CSS/JS, no build step is required.
1. Clone the repository.
2. Open `index.html` in your favorite browser.
3. Alternatively, run a local development server (e.g., Live Server extension in VS Code) for live reloading.
